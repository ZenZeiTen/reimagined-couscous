## Vassal's Edge — The Fall of Vareth-Ghar

`vassals-edge/` holds a King's Field-style dungeon crawler rebuilt on three.js r185 with a PSX-era Retro Forge
pipeline and a Blender model pipeline. See [vassals-edge/README.md](vassals-edge/README.md) for how to run it
(`npx http-server vassals-edge -p 8080`), the world, and the test tooling.
